## Version and status convention

Each writing record should identify its status, date and source or version. Use draft, ready for review, approved, submitted or published only when that state is supported. A draft stored in GitHub is still a draft for its intended recipient or publication.

Develop new text here. When a version is intended to replace website copy, update the relevant website source and the writing record together. Keep earlier framing explicitly labelled when it remains useful.

## Outreach

Save prepared contact language and recipient-specific drafts under `outreach/`, with the intended audience, source lead ID, preparation date and delivery status. Use only verified personal claims. Store sources and fit judgments in the [lead map](../research/phd-contact-map/README.md), and record delivery or replies only when they actually occur.
